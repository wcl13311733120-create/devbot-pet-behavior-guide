# 宠物行为管理与训练指南

基于 X 热搜话题 "小猫咪干的，这猫还能要吗？"（2.57M 曝光）开发的宠物行为管理 MVP。

## 功能

- **行为问题库**：10 种常见宠物行为问题（乱抓、咬人、 separation anxiety 等），含原因分析与解决方案
- **行为风险评估**：根据宠物类型、行为问题、频率、严重程度评估风险等级
- **训练课程**：5 门训练课程（基础服从、猫砂盆、分离焦虑、社会化、点击器）
- **记录管理**：记录宠物行为观察，支持 CRUD

## 技术栈

Node.js + Express + 纯 HTML/CSS/JS

## 运行

```bash
npm install
npm start
```

访问 http://localhost:3000
